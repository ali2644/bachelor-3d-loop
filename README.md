# bachelor-3d-loop
Automated closed-loop system for 3D printing quality control with robotic part handling, in-line measurement, and parameter optimization using Python.



Setup
Create Python Virtual Environment
python3 -m venv .venv
source .venv/bin/activate
Install Dependencies
pip install -r requirements.txt

If no requirements file is available yet:

pip install requests
pip install PrusaLinkPy
